# Бот для Telegram-канала со скидками и новостями об играх

Бот сам проверяет скидки в **Steam**, **GOG** и **Epic Games Store**,
бесплатные игры в Epic Games Store, а также свежие новости с игровых
сайтов — и публикует всё новое в ваш Telegram-канал на русском языке,
с ценами в 5 валютах. Работает бесплатно на GitHub Actions — свой сервер
не нужен.

**Если вы уже развернули более раннюю версию бота** — сразу переходите
к разделу [«Обновление уже работающего бота»](#обновление-уже-работающего-бота).
Первоначальная установка с нуля описана ниже, в основной инструкции.

---

## Что нового в этой версии

- **Русский язык.** Все новости и подписи — на русском. Названия игр,
  компаний и издателей не переводятся. Устоявшиеся термины (Steam, DLC,
  Early Access и т.д.) тоже остаются как есть.
- **Цены в 5 валютах** с флагами: 🇺🇸 USD, 🇷🇺 RUB, 🇰🇿 KZT, 🇺🇦 UAH, 🇧🇾 BYN.
  Если для какой-то валюты цены нет — строка просто не показывается.
- **Новое оформление постов** с разными эмодзи для Steam (⚙️), Epic Games (🎮)
  и GOG (🕹), отдельная пометка для бесплатных игр (🆓) и для особенно
  выгодных скидок (🔥).
- **Очередь публикаций с приоритетом.** Источники проверяются часто (каждые
  5 минут), но публикуется не всё сразу — см. раздел про частоту ниже.
- **Склейка похожих скидок.** Если у одного издателя одновременно много
  игр со скидкой (например, большая распродажа) — это один пост, а не
  десяток отдельных.
- **Обычные скидки Epic Games Store** (раньше бот отслеживал только
  еженедельную бесплатную игру).

## Частота проверки и публикации

Источники проверяются **каждые 5 минут**, но это не значит, что каждые
5 минут выходит пост. Всё найденное сначала попадает в очередь, а дальше
публикуется с учётом приоритета:

| Приоритет | Что это | Когда публикуется |
|---|---|---|
| 🔥 | Очень крупная скидка (от 75%, настраивается) | Практически сразу |
| 🆓 | Игра стала бесплатной | Практически сразу |
| 💰 | Обычная скидка (50–74%) | Из очереди, не чаще раза в 10–15 минут |
| 📰 | Обычная игровая новость | Из очереди, не чаще раза в 30–60 минут |

Так канал остаётся живым и оперативным (выгодные предложения выходят
быстро), но подписчики не получают пачку из десяти уведомлений подряд.

## ⚠️ Важно про расписание GitHub Actions и бесплатный лимит

У бесплатного GitHub есть лимит **2000 минут работы Actions в месяц**
для **приватных** репозиториев (для **публичных** репозиториев лимита
нет — это бесплатно и без ограничений).

Проверка каждые 5 минут — это до ~8600 запусков в месяц. Даже с учётом
того, что каждый запуск быстрый (особенно после первого — зависимости
кешируются), для **приватного** репозитория это может оказаться близко
к лимиту или превысить его, и тогда GitHub на какое-то время отключит
запуск по расписанию до начала следующего месяца.

**Что с этим делать (выберите один вариант):**

1. **Сделать репозиторий публичным** (рекомендую) — тогда лимита нет
   вообще. Код бота не содержит ничего секретного: токен и ID канала
   хранятся отдельно, в Secrets, и в самом коде их не видно. Сменить
   видимость: **Settings** → в самом низу страницы **Danger Zone** →
   **Change visibility** → **Make public**.
2. **Оставить приватным, но проверять реже** — в файле
   `.github/workflows/bot.yml` замените строку
   `cron: '*/5 * * * *'` на, например, `cron: '*/15 * * * *'`
   (каждые 15 минут — заметно меньше расходуемых минут).

Если ничего не менять и лимит всё же кончится — ничего не сломается
безвозвратно, просто автоматические запуски приостановятся до обнуления
лимита в начале следующего месяца (или до ручного запуска).

## Обновление уже работающего бота

Инструкция для тех, кто уже настроил бота раньше и хочет обновиться до
этой версии. DevOps-опыт не нужен — только браузер.

### Шаг 1. Скачайте новый архив и распакуйте его

Разархивируйте присланный файл `game-deals-bot.zip` на компьютере —
получится папка `game-deals-bot` со всеми файлами.

### Шаг 2. Загрузите новые файлы в ваш существующий репозиторий на GitHub

1. Откройте ваш репозиторий на github.com.
2. Нажмите **Add file** → **Upload files**.
3. Перетащите в окно браузера **всё содержимое** папки `game-deals-bot`
   (включая папку `.github` — она содержит обновлённое расписание).
4. GitHub покажет, какие файлы заменяются, а какие добавляются новыми —
   это ожидаемо, так и должно быть.
5. **Важно:** файл **`state.json` из архива загружать не нужно** — если
   вы его перезапишете, бот "забудет", что уже публиковал, и может
   ненадолго повторно опубликовать те скидки, которые всё ещё активны
   прямо сейчас. Если в списке загружаемых файлов появился `state.json` —
   просто уберите его (крестик рядом с файлом) перед тем, как нажать
   commit. Все остальные файлы, включая пустой `state.json` внутри
   архива, специально сделаны так, что старый `state.json` с ним
   прекрасно совместим — ничего вручную мигрировать не нужно.
6. Внизу страницы нажмите **Commit changes**.

### Шаг 3. Новые секреты не нужны

Все новые возможности (перевод, мультивалютность, очередь) работают без
дополнительных ключей API — токен бота и ID канала, которые вы уже
добавили в Secrets ранее, никак не меняются.

### Шаг 4. Определитесь с приватностью репозитория и расписанием

Прочитайте раздел [выше](#-важно-про-расписание-github-actions-и-бесплатный-лимит)
про лимит минут GitHub Actions и выберите вариант (сделать репозиторий
публичным или увеличить интервал проверки).

### Шаг 5. Запустите вручную и проверьте

1. Откройте вкладку **Actions** в репозитории.
2. Слева выберите **Game Deals Bot** → справа **Run workflow** → **Run workflow**.
3. Через минуту-две обновите страницу — должна появиться зелёная галочка
   у запуска. Откройте его и разверните шаг **Run bot** — в логе будет
   видно, что бот нашёл и что отправил (или почему не отправил ничего,
   если сейчас просто нет новых скидок/новостей).
4. Загляните в канал: если что-то было найдено — сообщения появятся в
   новом оформлении, на русском, с ценами в нескольких валютах.

### Как понять, что обновление прошло успешно

- В логе запуска (шаг **Run bot**) нет строк с текстом `Traceback` —
  значит, скрипт отработал без критических ошибок.
- Если видите строки вида `[gog] Не удалось получить цену ... в KZT` —
  это нормально и ожидаемо (см. раздел «Ограничения» ниже), это не
  поломка.
- Новое сообщение в канале выглядит как в примерах из раздела
  «Оформление постов» ниже (эмодзи платформы, приоритетный эмодзи,
  ссылка, строки с ценами).

Если что-то выглядит не так — скопируйте текст ошибки из лога и
пришлите мне, разберёмся.

## Ограничения и как к ним относиться

- **Перевод новостей автоматический и не идеальный.** Названия игр,
  которые бот уже видел среди скидок Steam/Epic/GOG, а также стандартные
  игровые термины (Steam, DLC, Early Access и т.п.) защищены от перевода
  и остаются как в оригинале. Но полностью надёжного распознавания ЛЮБЫХ
  имён собственных в свободном тексте не существует в бесплатном
  автоматическом решении — иногда редкое имя человека или студии, которое
  бот раньше не видел, может быть переведено вместе с остальным текстом.
  Если это будет происходить с конкретным именем регулярно — пришлите
  мне его, я добавлю в защищённый список в `translate.py`
  (`EXTRA_PROTECTED_TERMS`).
- **Мультивалютность GOG — "лучшее из возможного".** У GOG нет
  официального публичного API для цен в разных валютах, а по отзывам
  разработчиков сторонних инструментов существующий неофициальный
  эндпоинт **нестабилен**. Поэтому для GOG вы можете видеть меньше
  валютных строк, чем для Steam — это ожидаемо, а не баг. Также похоже,
  что у GOG в принципе нет отдельных цен в KZT и BYN, так что для GOG эти
  строки, скорее всего, никогда не появятся.
- **Обычные скидки Epic Games Store — самая новая и наименее проверенная
  часть проекта.** У Epic нет официального публичного API для списка
  скидок (в отличие от еженедельной бесплатной игры, которая работает
  много лет стабильно и не менялась). Используется сторонняя
  поддерживаемая библиотека, но если именно эта часть перестанет
  находить скидки или упадёт с ошибкой — остальной бот (Steam, GOG,
  бесплатные игры Epic, новости) продолжит работать как обычно: ошибки
  в одном источнике не влияют на другие.
- Как и раньше: **PlayStation Store, Xbox и Nintendo eShop** не
  включены — у них нет стабильного бесплатного источника данных.

Если что-то из перечисленного выше начнёт вести себя не так, как
описано (например, GOG вообще перестанет показывать цены, или в логах
будут регулярные ошибки одного и того же вида) — пришлите мне текст
ошибки из вкладки Actions, поправлю.

## Как что-то настроить

Все настройки — простой текст в файле `main.py`, в самом верху (раздел
`НАСТРОЙКИ`). Править можно прямо в браузере на GitHub: открыть файл →
карандаш "Edit" → изменить → Commit changes.

| Что настроить | Где | Значение по умолчанию |
|---|---|---|
| От какой скидки постить вообще | `MIN_DISCOUNT_STEAM`, `MIN_DISCOUNT_GOG`, `MIN_DISCOUNT_EPIC` | 50 (%) |
| От какой скидки считать "горячей" (🔥, публикуется почти сразу) | `HOT_DISCOUNT_THRESHOLD` | 75 (%) |
| От скольких скидок одного издателя склеивать в один пост | `BUNDLE_MIN_COUNT` | 4 |
| Интервал публикации обычных скидок (💰) | `TIER_INTERVAL_SECONDS["deal"]` | 720 сек (12 мин) |
| Интервал публикации обычных новостей (📰) | `TIER_INTERVAL_SECONDS["news"]` | 2700 сек (45 мин) |
| Сколько сообщений максимум слать за один запуск | `MAX_POSTS_PER_RUN` | 10 |
| Какие новостные сайты использовать | `sources/news.py`, список `FEEDS` | RPS, PC Gamer, PCGamesN |
| Фильтр новостей по ключевым словам | `sources/news.py`, `REQUIRED_KEYWORDS` | пусто (без фильтра) |
| Как часто проверять источники | `.github/workflows/bot.yml`, `cron` | каждые 5 минут |

## Первоначальная установка (если разворачиваете бота впервые)

### Шаг 1. Создайте Telegram-канал (если его ещё нет)

В Telegram: **Новый канал** → задайте название → сделайте его публичным
и придумайте юзернейм (например `@my_game_deals`).

### Шаг 2. Создайте Telegram-бота и получите токен

1. Откройте в Telegram диалог с **@BotFather**.
2. Отправьте `/newbot`, следуйте инструкциям.
3. Сохраните полученный **токен** — длинную строку вида
   `123456789:AAExampleTokenAAAAAAAAAAAAAAAAAAAA`. Никому его не показывайте.

### Шаг 3. Добавьте бота администратором канала

Настройки канала → **Администраторы** → **Добавить администратора** →
найдите бота → дайте право **публиковать сообщения**.

### Шаг 4. Узнайте ID канала

- Публичный канал — используйте юзернейм с `@`, например `@my_game_deals`.
- Приватный канал — перешлите сообщение из канала боту **@userinfobot**,
  он покажет числовой ID вида `-1001234567890`.

### Шаг 5. Разместите код на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com).
2. **New repository** → название (например `game-deals-bot`) →
   решите, публичный или приватный (см. раздел про лимит Actions выше) →
   создайте репозиторий.
3. **Add file** → **Upload files** → перетащите содержимое папки
   `game-deals-bot` из архива (включая `.github`) → **Commit changes**.

### Шаг 6. Добавьте секреты

**Settings** → **Secrets and variables** → **Actions** →
**New repository secret**:

| Имя секрета | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из Шага 2 |
| `TELEGRAM_CHAT_ID` | `@username` или числовой ID из Шага 4 |

### Шаг 7. Запустите и проверьте

Вкладка **Actions** → разрешите запуск workflow, если попросит → слева
**Game Deals Bot** → **Run workflow**. Через минуту-две проверьте
результат (зелёная/красная галочка) и загляните в канал.

Дальше бот будет запускаться сам по расписанию — ничего делать не нужно.
