# Бот для Telegram-канала со скидками и новостями об играх

Что делает: раз в несколько часов сам проверяет скидки в **Steam** и **GOG**,
бесплатные игры в **Epic Games Store**, а также свежие новости с игровых
сайтов (**Rock Paper Shotgun**, **PC Gamer**, **PCGamesN**) — и публикует
всё новое в ваш Telegram-канал. Уже опубликованное повторно не постится.

Работает бесплатно на GitHub Actions — свой сервер не нужен.

**Важно про PlayStation, Xbox, Nintendo:** у этих магазинов нет надёжного
бесплатного публичного источника данных о скидках (в отличие от Steam,
Epic и GOG). Подробнее — в разделе "Ограничения" внизу.

---

## Шаг 1. Создайте Telegram-канал (если его ещё нет)

В Telegram: **Новый канал** → задайте название → сделайте его публичным
и придумайте юзернейм (например `@my_game_deals`) — так будет проще всего
подключить бота. Приватный канал тоже подойдёт, но настройка будет на шаг
сложнее (см. Шаг 4).

## Шаг 2. Создайте Telegram-бота и получите токен

1. Откройте в Telegram диалог с **@BotFather**.
2. Отправьте команду `/newbot`.
3. Придумайте имя бота (любое) и юзернейм, оканчивающийся на `bot`
   (например `MyGameDealsBot`).
4. BotFather пришлёт **токен** — длинную строку вида
   `123456789:AAExampleTokenAAAAAAAAAAAAAAAAAAAA`.
   Сохраните его — он понадобится в Шаге 6. Никому его не показывайте.

## Шаг 3. Добавьте бота администратором канала

В настройках вашего канала: **Администраторы** → **Добавить администратора**
→ найдите вашего бота по юзернейму → дайте ему право **публиковать сообщения**.

## Шаг 4. Узнайте ID канала

- Если канал **публичный** — просто используйте его юзернейм вместе с `@`,
  например `@my_game_deals`. Он и есть нужный ID.
- Если канал **приватный** — перешлите любое сообщение из канала боту
  **@userinfobot** (или **@getidsbot**) — он покажет числовой ID вида
  `-1001234567890`. Именно это значение (вместе с минусом) и нужно будет
  использовать.

## Шаг 5. Разместите код на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com), если аккаунта ещё нет.
2. Нажмите **New repository**, дайте название (например `game-deals-bot`),
   выберите **Private** (чтобы код был виден только вам) и создайте репозиторий.
3. На странице репозитория нажмите **Add file** → **Upload files**.
4. Перетащите в окно браузера **все файлы и папки** из архива, который
   я подготовил (включая скрытую папку `.github` — распакуйте архив на
   компьютере и перетаскивайте содержимое папки `game-deals-bot`, а не саму
   папку). Современный GitHub сохраняет структуру папок при перетаскивании.
5. Нажмите **Commit changes**.

*Альтернатива для тех, кто не любит браузерную загрузку:* можно установить
[GitHub Desktop](https://desktop.github.com) — там всё делается кнопками,
без командной строки.

## Шаг 6. Добавьте секреты (токен и ID канала)

В репозитории: **Settings** → **Secrets and variables** → **Actions** →
**New repository secret**. Добавьте два секрета:

| Имя секрета | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из Шага 2 |
| `TELEGRAM_CHAT_ID` | `@username` или числовой ID из Шага 4 |

## Шаг 7. Запустите и проверьте

1. Откройте вкладку **Actions** в репозитории.
2. Если GitHub спросит, разрешите запуск workflow (**I understand my
   workflows, go ahead and enable them**).
3. Слева выберите **Game Deals Bot** → справа нажмите **Run workflow** →
   **Run workflow** ещё раз для подтверждения.
4. Через минуту-две обновите страницу — должен появиться запуск с зелёной
   галочкой. Загляните в канал — должны появиться посты (если сейчас
   правда есть скидки от 50% и новые новости).
5. Если галочка красная — откройте запуск и посмотрите текст ошибки в
   логе (шаг "Run bot"). Можно скопировать этот текст и прислать мне —
   разберёмся.

Дальше бот будет запускаться сам каждые 3 часа по расписанию — ничего
делать не нужно.

## Как что-то настроить

Все настройки — простой текст, править можно прямо в браузере на GitHub
(открыть файл → карандаш "Edit" в правом верхнем углу → Commit changes).

- **Как часто публиковать** — файл `.github/workflows/bot.yml`, строка
  `cron: '0 */3 * * *'` (сейчас каждые 3 часа). Например, `0 */6 * * *` —
  каждые 6 часов, `0 9,18 * * *` — дважды в день в 9:00 и 18:00 UTC.
- **От какой скидки постить** — файл `main.py`, строки `MIN_DISCOUNT_STEAM`
  и `MIN_DISCOUNT_GOG` (сейчас 50, то есть скидки от 50%).
- **Регион/валюта Steam и GOG** — там же, `STEAM_COUNTRY`, `GOG_COUNTRY`
  и т.д.
- **Какие новостные сайты использовать** — файл `sources/news.py`,
  список `FEEDS`. Можно добавить любой сайт со своим RSS-фидом — просто
  добавьте строку `("Название", "ссылка_на_фид"),`.
- **Фильтр новостей по ключевым словам** — там же, `REQUIRED_KEYWORDS`.
  Пусто — публикуются все новости. Например
  `["announce", "release date", "trailer", "анонс"]` оставит только то,
  что похоже на анонсы новинок.

## Ограничения и что можно добавить позже

- **PlayStation Store, Xbox, Nintendo eShop** не включены в эту версию.
  У Steam, Epic и GOG есть стабильные источники данных, которыми давно
  и надёжно пользуются сторонние сайты и боты. У консольных магазинов
  такого бесплатного и стабильного варианта нет: официальных публичных
  API для скидок там просто не существует, а неофициальные — либо часто
  меняются и ломаются без предупреждения (Nintendo), либо устроены
  значительно сложнее и требуют дополнительной проверки (Xbox), либо
  доступны только по платной подписке на сторонний сервис (например
  PlatPrices — для PlayStation, от 19$/мес после бесплатного лимита).
  Я не стал включать в готовое решение то, что с высокой вероятностью
  сломается без возможности для вас самостоятельно это починить.
- Xbox технически можно добавить — есть открытый (хоть и неофициальный)
  способ получить его каталог скидок, просто он двухшаговый и сложнее
  устроен. Если хотите — могу добавить отдельным шагом, тогда вместе
  проверим результат по логам в Actions.
- Если что-то из источников Steam/Epic/GOG сломается (магазины иногда
  меняют формат ответа) — бот не упадёт целиком, а просто пропустит
  этот источник и напишет об этом в лог. Пришлите мне текст ошибки из
  вкладки Actions — поправлю код.
